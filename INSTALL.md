# Installation Instructions

## Option 1: Download and Extract (Easiest)

1. Download the `movie-tracker-app` folder from Claude
2. Move it to your desired location:
   ```bash
   mv ~/Downloads/movie-tracker-app /Users/chadcribbins/Work/WE3io/playgrounds/
   ```
3. Navigate to the project:
   ```bash
   cd /Users/chadcribbins/Work/WE3io/playgrounds/movie-tracker-app
   ```
4. Run the setup script:
   ```bash
   ./setup.sh
   ```
   Or manually install:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```

## Option 2: Manual Setup

If you downloaded individual files, create the folder structure first:

```bash
cd /Users/chadcribbins/Work/WE3io/playgrounds
mkdir movie-tracker-app
cd movie-tracker-app
```

Then move/copy all the downloaded files into this directory and run:
```bash
npm install
npm run dev
```

## Opening in Cursor

Once the project is in place:

1. Open Cursor
2. File → Open Folder
3. Navigate to `/Users/chadcribbins/Work/WE3io/playgrounds/movie-tracker-app`
4. Click "Open"

You're ready to develop! 🚀
